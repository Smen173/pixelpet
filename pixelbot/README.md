# PixelBot 🟣

Милый пиксельный бот на Python + Tkinter.
Смотрит за курсором, реагирует на клики и перетаскивается мышкой.

## Возможности
- 👀 Глаза следят за курсором в реальном времени
- 🎨 Клик меняет цвет тела на случайный
- 😮 Правая кнопка мыши — перетаскивание окна, рот «открывается»
- ⌨️ Alt(левый) — переключить улыбку
- ⌨️ Alt(правый) — переключает цвет тела, Esc — закрыть

## Установка и запуск
Нужен только Python 3.8+. Tkinter входит в стандартную поставку.
